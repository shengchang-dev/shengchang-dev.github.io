# 公版文本清单（可合法改编与配音）

> 本清单的网页版（带排版）见本站 [公版文本清单](https://shengchang-dev.github.io/classics/)。

「公版」指版权保护期已届满的作品。按我国著作权法，自然人作品的财产权保护期为作者终生及其死亡后 50 年。本清单只收录作者去世已满 50 年的作品，并标注卒年与底本，改编、配音、公开发布前请自行复核译本版权：**译本有独立版权，现代译者的译文不等于公版**，优先使用原文或译者同样已过保护期的译本。

这些文本适合在 [光年声场](https://aishengchang.com) 里做成多人有声剧公开分享，也是「公版剧场」计划的选篇池。

## 使用方式

1. 选篇后准备干净文本（原文或自有改写），注明作者、卒年、底本
2. 在 [光年声场](https://aishengchang.com) 粘贴文本，AI 分角色、分音色生成
3. 作品页标注「AI 生成」与原作信息后再公开发布
