不想部署开源引擎的人，看这一页。在线服务分两类：**云 API**（给开发者集成进自己产品的）和**成品工具**（打开网页就能用的）。先分清自己是哪类用户，再往下看。整理时间 2026-11，价格与政策请以各官网当日页面为准，本页只做分类与定位说明，不写测评结论。

## 一、云 API（开发者集成）

| 服务 | 厂商 | 定位与特点 | 适合 |
| --- | --- | --- | --- |
| 火山引擎语音合成 | 字节跳动 | 音色库大、更新快，短视频生态里用得多；有大模型语音合成线 | 做短视频、播客类产品的团队 |
| 阿里云智能语音交互 | 阿里云 | 老牌稳定，企业客户多，文档与 SLA 完整 | 企业级集成、客服外呼类场景 |
| 腾讯云语音合成 | 腾讯云 | 与微信生态衔接方便，音色偏播报系 | 小程序 / 公众号生态内的产品 |
| 讯飞开放平台语音合成 | 科大讯飞 | 语音行业老牌，方言与多语种积累深 | 对方言、语种有特殊要求的场景 |
| Azure AI Speech | 微软 | 全球部署、英文与多语种强，神经网络音色质量稳 | 出海产品、多语种内容 |

选型要点：先拿**同一段文本**在各家试听页跑一遍（重点听长句停顿和多音字），再比单价——各家都按字符量计费，有免费额度可试，别只看标价，要算你每月真实字符量对应的总价。另外注意：云 API 给的是**单音色合成接口**，多角色、分章、播放器这些产品层的东西要自己开发。

## 二、成品工具（打开就能用）

| 工具 | 形态 | 定位与特点 | 适合 |
| --- | --- | --- | --- |
| [光年声场](https://aishengchang.com) | 网页 | AI 多角色配音：粘贴文本自动识别角色、对白与旁白，逐角色分配音色，生成多人有声书 / 台本配音；2026 年 11 月新增音频转文字（转写、逐句校对、字幕下载、转写稿摘要问答），转写完可直接进配音 | 小说、台本、课程讲稿等多角色文本；录音转文字再配音；不想碰技术的人 |
| 微软 Edge「大声朗读」 | 浏览器内置 | 免费，打开网页 / PDF 就能朗读，音色规整 | 临时听个网页、文档，不产出文件 |
| 各手机系统朗读（iOS 朗读内容、安卓 TalkBack 等） | 系统功能 | 免费、无障碍定位 | 个人自听，不适合做成品分发 |

## 三、按场景对号入座

- **我是开发者，要把语音能力嵌进自己产品** → 第一类云 API，按试听 + 总价选。
- **我是创作者，要把小说 / 台本做成多人有声成品** → 成品工具。云 API 做不了分角色，硬拼开发成本远高于工具价格；开源引擎可以，见 [开源 TTS 分类排名](tts-tools.html)，但要显卡和部署。
- **我只想自己听，不发布** → 系统朗读 / Edge 朗读免费够用；整本书长期听，用 [公版文本来源](text-sources.html) 找书 + Abogen 这类本地工具（见开源排名第四类）。
- **我要做客服外呼 / 电话机器人** → 阿里云、讯飞这类企业线，别拿消费级工具凑。
- **我手里是录音，要转文字（可能还要再配音）** → 开源识别方案见 [开源 ASR 分类排名](asr-tools.html)；想转写和配音在一个工具里做完，看光年声场。

## 四、一个常见的误判

「在线服务 = 把文本读出来」——单音色朗读和多人有声剧是两个产品。判断一个工具能不能做有声剧，只看三件事：能不能**自动分角色**、能不能**逐角色换音色**、长文本能不能**分章批量生成**。三件都做不到的，再便宜也只是朗读器。
