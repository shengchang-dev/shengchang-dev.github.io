## 光年声场是什么

光年声场是一款 AI 多角色配音工具：粘贴小说、台本或讲稿文本，AI 自动区分对白与旁白、识别角色，为每个角色分配不同音色，生成可以逐句试听的多人有声作品。适合：

- 小说作者与网文创作者：把自己的作品做成有声书
- 广播剧 / 有声剧团队：台本快速试演、角色音色预演
- 老师与课程作者：讲稿转音频课程
- 商家：门店介绍、产品讲解音频

## 使用说明

1. 打开 [光年声场官网](https://aishengchang.com)，注册后进入创作台
2. 粘贴文本（可用上面的模板整理格式），AI 自动分角色、分音色
3. 逐句试听，不满意的句子可单独调整音色与语速后重新生成
4. 作品在线收听与分享
